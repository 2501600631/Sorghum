# 高粱近红外实验包：98个独立样本（V13.2.0-98）

## 简单运行顺序

建议解压到短路径，例如 `D:\NIR98`。在 Anaconda Prompt 中进入解压后的 NIR98 文件夹。

1. 安装依赖：`python -m pip install -r requirements.txt`
2. 核验数据和程序：`python run_v13_1_validate.py --verify-checksums`
3. 测试完整流程：`python run_v13_1_smoke_test.py`
4. 第3步成功后，正式运行四个指标：`python run_v13_1_analysis.py`

也可依次双击 `01_check.bat`、`02_smoke.bat`、`03_formal.bat`。必须确保当前 python 环境已安装依赖。窗口会保留成功或失败提示；出现错误先解决，不要继续下一步。

数据已整理并随包冻结，正常使用无需重新导入。正式运行耗时明显长于流程测试，请保持电脑运行。正式目录必须为空，程序会拒绝覆盖已有正式结果。

## 结果位置

- `v13_2_smoke_results`：98个样本、四个指标，外层2折×1次、内层2折，缩小候选模型空间。仅用于软件流程检查，不用于论文结论。
- `v13_2_results`：正式四指标实验，外层5折×10次、内层4折。
- `v13_2_results/03_performance/method_performance_summary.csv`：模型性能汇总。
- `v13_2_results/01_predictions/all_targets_outer_oof_predictions.csv`：每个样本每次外层交叉验证的预测。
- `v13_2_results/04_inference`：整粒强基线与粉碎辅助模型的配对统计比较。
- `v13_2_results/05_utility_boundary`：粉碎辅助增益与回顾性选择粉碎分析。
- `v13_2_results/06_robustness`：敏感性、校正重复交叉验证及固定预测的标签置换诊断。
- `v13_2_results/00_audit/formal_run_freeze_receipt.json`：正式计算完成后的输入、代码绑定凭证。

正式结果应有58,800行折外预测（4指标×15方法×98样本×10次）；每个指标、方法、样本对应10次预测。汇总样本预测时可按 sample_id 对这10个 y_pred 求均值，但不可把10次预测视为10个独立样本。性能主报告保留每次完整折外预测计算的指标。

## 本次调整

- 以用户2026-09-15明确说明的98个独立样本为实验单位。完整编号（包括末尾1/2）保留，每个样本一条整粒光谱、一条粉碎光谱、一组理化值；两种形态属于同一样本的配对数据。
- 不再把同前缀的两行合并为49行，不对其理化值求平均，也不把它们用于技术重复精密度估计。
- 输入光谱400–2499.5 nm、0.5 nm间隔，共4200点；沿用预先设定的2 nm建模网格400–2498 nm，共1050点。
- 原算法家族、三分支独立筛选、同折公平比较和固定种子20260830保留。正式模式保留30种光谱表示，每分支保留2种；没有根据新数据预测成绩调整模型或种子。
- 数据读取、样本数校验、自检、正式结果行数和版本签名已适配；新增原表逐行映射、原始输入与代码哈希、真实理化值对照、内外层划分隔离检查。
- 技术重复分析输出改为明确的“不适用”状态，其他统计与效用分析继续保留。
- 文件名中的 v13_1 为兼容原有入口而保留，实际代码/配置版本为13.2.0-98。旧49样本结果和旧测试通过记录不作为本包证据。

## 数据可追溯性

`raw_inputs` 保留本次两份原始工作簿。`experimental_data/sample_alignment.csv` 给出完整样本编号及三张原表的Excel行号。`DATA_IMPORT_AUDIT.json` 记录工作表、数量、范围、数据摘要和原表哈希。CSV文件名中的 replicate 为兼容接口，每个ID仅有 replicate=1；程序中三维数组的观察轴长度为1，没有复制光谱制造重复。

独立性依据是本次用户说明；田间来源、批次、品种以及理化参考方法的实验记录未由这两份表完整提供，模板保留空白。模型计算默认按98个独立ID划分。如果后续记录表明多个样本共享必须隔离的来源组，应补全所有 source_group 并重新冻结、重跑。来源组留空不会阻止本次内部建模，但严格投稿元数据检查不会因此通过。

这仍是内部重复嵌套交叉验证，没有新增独立外部验证。原研究的候选方法受过既往开发分析影响。固定预测的标签置换没有重训完整流程；选择性粉碎是回顾性分析。新版本可正确处理98样本，不承诺任何指标或模型必然提高。

## 后续更新数据或实验记录

仅在确需替换输入时：保存完整旧正式结果目录到其他位置，更新 raw_inputs 内原表，运行 `python prepare_data.py`，必要时补全 experimental_data 内两个元数据模板，然后运行 `python freeze_package.py`，再从核验、测试、正式计算重新开始。重新冻结意味着一个新的计算版本；不能用它给旧结果补签。

可选：`python run_v13_1_algorithm_selftest.py` 检查20个算法家族分支；`python run_v13_1_submission_readiness.py` 在正式运行和实验记录齐备后检查投稿元数据与结果绑定。无需先跑两指标 primary-check，它会重复大量计算。

完整软件验证状态见 `docs/DELIVERY_QA.md`。交付包不预装第三方Python环境。
