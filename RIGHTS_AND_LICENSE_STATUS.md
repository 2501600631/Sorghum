# Rights and licence status

This repository currently has no code, data or figure licence. Public availability provides access; reuse permissions depend on the applicable rights and any permission obtained from the authors or other rights holders.

The authors can add licences after confirming redistribution rights for the data, analysis code, source workbooks and figures, including contributions from collaborating institutions. Code and data may use separate licences. The 20 October 2026 documentation revision leaves that choice with the authors.

Third-party Python implementations are installed through `requirements.txt` and retain their own licences. Runtime libraries, private correspondence and manuscript submission documents are outside this dataset and analysis package.
